# Chaos Subs

Перевод видео YouTube и сохранённых трансляций Twitch на русский с субтитрами внутри плеера.

**Windows 10/11 x64 · Microsoft Edge / Google Chrome · бета-версия**

## Скачать

Откройте [выпуски](https://github.com/Silumgaaar/chaos-subs/releases) и скачайте установщик **Chaos-Subs-Setup-…exe** из раздела **Assets** последнего опубликованного выпуска.

ZIP **Chaos-Subs-…zip** предназначен для ручной установки. Архивы **Source code**, которые добавляет GitHub, не являются установочным пакетом приложения.

## Установка

1. Запустите установщик и выберите Chrome или Edge.
2. Дождитесь подготовки Python и зависимостей. При первой установке нужны интернет и несколько гигабайт свободного места.
3. По подсказкам установщика откройте страницу расширений браузера, включите режим разработчика и загрузите указанную папку расширения через «Загрузить распакованное».
4. Вставьте ID расширения в установщик и завершите подключение.
5. Откройте Chaos Subs через значок расширения и включите приложение.

Права администратора не требуются. Папка установки: `%LOCALAPPDATA%\Programs\Chaos Subs`.

## Настройка

- **Локально:** установите HY-MT2 7B и модель Whisper во вкладке «Модели». Скорость зависит от компьютера; модели скачиваются отдельно.
- **Gemini / Groq:** добавьте собственные API-ключи и проверьте условия бесплатного тарифа сервиса.
- **ChatGPT:** подключите аккаунт; доступность моделей и лимиты зависят от аккаунта.
- На YouTube можно использовать доступную оригинальную дорожку субтитров вместо распознавания звука.

В плеере выберите настроенные переводчик и распознавание, начало и длительность фрагмента. Опция **«Смотреть во время перевода»** постепенно подготавливает запись. Если просмотр догонит перевод, видео подождёт. Режим предназначен для записей; при дальней перемотке может понадобиться ожидание.

## Обновление

В настройках нажмите **«Проверить обновления»**. Проверка выполняется только по запросу. Откройте страницу нового выпуска и скачайте установщик.

Перед установкой завершите текущую задачу и выключите Chaos Subs. Установщик обновляет стандартную папку установки. При нестандартном размещении используйте ZIP для обновления файлов в прежней папке. Затем перезагрузите расширение на `edge://extensions` или `chrome://extensions` и обновите страницы видео.

Настройки, ключи, модели и готовые переводы хранятся в `data` и не входят в чистый дистрибутив. Не удаляйте эту папку и `.venv` при ручном обновлении.

## Данные и диагностика

В локальном режиме распознавание и перевод выполняются на компьютере; сеть требуется для получения видео, загрузки моделей и ручной проверки обновлений. При выборе облачного сервиса соответствующие данные отправляются этому сервису.

В диспетчере задач приложение видно как **ChaosSubs.exe**. Закрытие его окна завершает локальный сервер и дочерние процессы моделей.

Об ошибках сообщайте в [Issues](https://github.com/Silumgaaar/chaos-subs/issues). Укажите версию, браузер, выбранные способы распознавания и перевода, шаги воспроизведения и код ошибки. Не публикуйте API-ключи, файлы `data`, токены и полные личные журналы.
